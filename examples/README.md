# Examples

Sources only: rendered media isn't committed. Each folder renders with the matching skill's scripts.

| Folder | Skill | Render |
|---|---|---|
| `infrazero/` | video-basic | `python3 ../../skills/video-basic/scripts/render.py video index.html infrazero.mp4` |
| `homelab-nut/` | video-pro | copy `../../skills/video-pro/scripts/*.py` in, then `python3 render.py all` |

The mascots in `homelab-nut/` belong to [homelab-nut](https://github.com/rtorcato/homelab-nut).
